# Portfolio 与账户仓库合并验收 · 2026-10-14

## 验收范围

Python 3.11，本机 PostgreSQL、NATS JetStream，服务通过正式脚本构建和安装 wheel。业务代码收拢为 account-service 一个仓库；OMS/Risk/Portfolio 同一 OS 进程，Execution 和策略仍独立。Docker、实盘与长期负载未验收。

## 自动验证

新增 28 项账本、数据库、生命周期、快照与配置测试，以及 6 项策略运行器测试通过。覆盖：

- 移动平均成本、部分减仓、穿零、股票／期权乘数、价差逐腿现金流；费用单独列支。
- 重复事件、序列缺口、重启投影、手续费版本乱序、成交更正和零数量撤销、无效更正事务回滚。
- 相反方向策略独立归属；外部仓位、快照过期、未完成、窗口内账本变化；重复合约映射拒绝。
- 券商查询等待完成标志，超时不能返回空仓成功；采集中成交标记不稳定；查询不占用发单锁。
- 同进程账户／执行模式／消息地址／策略集合／合约版本一致；模块数据库分离；任一核心模块故障关闭所有模块。
- Risk 拒绝错误模式、错误 epoch、落后水位或不就绪 Portfolio；策略持仓变化进入串行回调，非匹配状态禁止新增风险而保留撤单路径。

从此前私有归档取出的既有回归测试也通过：Execution 33 项、Risk 24 项、OMS／策略 26 项，共 83 项。临时测试使用单独数据库，不操作业务数据库。

独立审查发现策略主动查询未更新下单缓存的问题，已通过 4 项先失败后通过的复现测试修正：过期缓存禁止新单，查询 STALE 或失败立即撤销缓存就绪，OMS/Portfolio epoch 不同则拒绝使用。回归测试未发现其他待修的重要问题。

## 真实本机进程的模拟链路

安装后的 `account-runtime` 一个进程运行 OMS/Risk/Portfolio，连接专用临时 NATS 和三个独立 PostgreSQL 库。临时执行模拟器提供只读券商快照和合成执行回报，策略侧使用安装的 OmsClient / PortfolioClient。

- 提交 2 股模拟买入，真实 Risk 审批后由模拟执行器回报成交与费用。
- Portfolio 得到数量 2、成交价 10、手续费 1、交易现金流 -21；与模拟券商数量匹配。
- 策略查询账户详情和其他策略 subject 均被 NATS ACL 拒绝。
- 账户进程停止并重启，持仓投影保持一致。
- 仅终止 Portfolio 的 PostgreSQL 后端连接，整个账户进程非零退出，三个模块一同停止。

这轮成交是合成回报，不是 IB 成交，也未验证策略行情驱动的新鲜度或实际交易时段。

## IB Gateway 只读联调

本机 `127.0.0.1:4002`，严格匹配一个模拟账户；完整账号仅保留在进程私有环境。Execution 使用 `--account-only`，账户服务使用 IB_PAPER，均为安装后的程序和独立临时数据库。

收到 1 个券商持仓、4 个账户资金字段。Portfolio 返回 `EXTERNAL_OR_UNEXPLAINED`，存在 1 个未分配差异，策略持仓仍为 0。没有自动改变策略归属；本轮 IB 下单数 **0**，撤单数 **0**。

本结果验证新鲜只读采集、来源绑定与归属边界，不证明实际成交、更正、行权或指派的端到端券商处理。原 IB 执行交易验收保留在 Execution 文档。
